## [1.0.0] - 2026-08-26

### Added

* Topic based question practice.
* Timed mock exams with 20 randomly selected questions.
* Automatic answer correction and score calculation.
* Pass or fail results based on the required passing score.
* Responsive interface for desktop and mobile devices.
* Responsive application navigation.
* Local exam question data organized by topic.
